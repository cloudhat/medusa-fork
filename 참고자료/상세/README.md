## 요구사항 항목별 Gap 요약

Medusa가 지원하지 않아 **직접 구현이 필요한 항목**:

| 항목 | 내용 | 참조 |
|------|------|------|
| 부분 반품 후 배송비 재청구 | 반품으로 무료배송 임계값 이탈 시 자동 배송비 복원 없음 | [배송비-그룹-조건부무료.md](배송비-그룹-조건부무료.md) |
| 배송 그룹 강제 분리 | `ShippingProfile` 기반 그룹 분리를 UI에서 직접 처리해야 함 | [배송비-그룹-조건부무료.md](배송비-그룹-조건부무료.md) |
| 반품 후 쿠폰 조건 이탈 처리 | `PROMOTION_REMOVE`가 반품 워크플로우에 미연동 | [부분반품-환불-흐름.md](부분반품-환불-흐름.md) |
| `accounting_total` 정합성 | `processActions()` 후 크레딧 공제가 유지되지 않는 구조 | [정산-과세-구조.md](정산-과세-구조.md) |
