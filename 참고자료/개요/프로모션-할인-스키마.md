# 프로모션/할인 모듈 스키마

Promotion 모듈의 DB 엔티티 구조. 쿠폰 적용 범위, 할인 계산 방식, 할인액 분담 구조 중심으로 정리.

상위: [README.md](README.md)

---

## 엔티티 관계도

```
Campaign
 ├── CampaignBudget
 │    └── CampaignBudgetUsage[] (속성별 사용량)
 └── Promotion[]
      ├── ApplicationMethod
      │    ├── target_rules → PromotionRule[] (할인 대상 범위)
      │    └── buy_rules → PromotionRule[] (buyget 구매 조건)
      └── rules → PromotionRule[] (프로모션 적용 조건)

PromotionRule
 └── PromotionRuleValue[]
```

## 핵심: 할인 적용 범위와 계산 방식

### ApplicationMethod
[`packages/modules/promotion/src/models/application-method.ts`](../../packages/modules/promotion/src/models/application-method.ts)

**할인 대상 범위** (`target_type`):

| 값 | 적용 범위 |
|----|----------|
| `order` | 주문 전체에 적용 |
| `items` | 특정 상품 라인 아이템에만 적용 |
| `shipping_methods` | 배송비에만 적용 |

**할인 방식** (`type`):

| 값 | 의미 |
|----|------|
| `fixed` | 고정 금액 할인. `value` + `currency_code` 사용 |
| `percentage` | 퍼센트 할인. `value`가 퍼센트 수치 (예: `10` = 10%) |

**할인액 분담 방식** (`allocation`) — `target_type=items`일 때:

| 값 | 의미 | 정산/과세 영향 |
|----|------|--------------|
| `each` | 조건에 맞는 각 아이템마다 개별 적용 | 아이템별 할인액 = 동일 |
| `across` | 조건에 맞는 아이템 전체에 분산 적용 | 아이템별 할인액 = 비례 배분 |
| `once` | 한 번만 적용 | |

요구사항의 "할인액수를 어떻게 상품 간에 분담할지에 따라 과세 신고액이 바뀐다" 항목은 이 `allocation` 필드로 제어.

**수량 관련 필드**:

| 필드 | 타입 | 비고 |
|------|------|------|
| `value` | bigNumber, nullable | 할인 값 |
| `max_quantity` | number, nullable | 할인 적용 최대 수량 |
| `apply_to_quantity` | number, nullable | buyget: 무료/할인 제공 수량 |
| `buy_rules_min_quantity` | number, nullable | buyget: 구매 최소 수량 조건 |

## 적용 범위 세부 제어: PromotionRule

### PromotionRule
[`packages/modules/promotion/src/models/promotion-rule.ts`](../../packages/modules/promotion/src/models/promotion-rule.ts)

특정 상품/상품 그룹에만 쿠폰을 적용할 때 `ApplicationMethod.target_rules`로 연결.

| 필드 | 타입 | 비고 |
|------|------|------|
| `attribute` | text | 비교 대상 속성 (예: `product_id`, `product_type_id`, `customer_group`) |
| `operator` | enum | `gte` / `lte` / `gt` / `lt` / `eq` / `ne` / `in` |

### PromotionRuleValue
[`packages/modules/promotion/src/models/promotion-rule-value.ts`](../../packages/modules/promotion/src/models/promotion-rule-value.ts)

| 필드 | 타입 |
|------|------|
| `value` | text |

예시 — 특정 상품에만 쿠폰 적용:
```
PromotionRule:
  attribute = "product_id"
  operator  = "in"
  values    = [{ value: "prod_abc" }, { value: "prod_xyz" }]
```

예시 — 특정 브랜드 상품 그룹에만 적용 (product_collection 활용):
```
PromotionRule:
  attribute = "product_collection_id"
  operator  = "in"
  values    = [{ value: "pcol_brand_a" }]
```

## 피벗 테이블 요약

| 테이블명 | 연결 관계 | 용도 |
|---------|----------|------|
| `promotion_promotion_rule` | Promotion ↔ PromotionRule | 프로모션 적용 조건 |
| `application_method_target_rules` | ApplicationMethod ↔ PromotionRule | 할인 대상 범위 조건 |
| `application_method_buy_rules` | ApplicationMethod ↔ PromotionRule | buyget 구매 조건 |

## 자동 적용 vs 코드 입력

- `is_automatic = true`: 조건 충족 시 코드 입력 없이 자동 적용 (기획전 할인 등)
- `is_automatic = false`: `Promotion.code`를 명시적으로 입력해야 적용 (쿠폰 코드)

두 방식 모두 `PromotionRule`로 적용 조건을 동일하게 표현.
