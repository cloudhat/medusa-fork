# 주문 모듈 스키마

Order 모듈의 DB 엔티티 구조. 금액 불변성, 버전 관리, 부분 반품 구조를 중심으로 정리.

상위: [README.md](README.md)

---

## 핵심 설계 원칙

**이중 레이어 구조**: 주문 확정 시점의 불변 스냅샷 + 이후 상태 변화 추적을 분리.

```
OrderLineItem   (불변 스냅샷: 주문 당시 상품 정보/단가)
OrderItem       (버전별 상태: 수량 처리 현황, 반품 현황)

OrderShippingMethod  (배송비 금액 데이터)
OrderShipping        (버전별 연결 테이블)
```

**버전 관리**: `Order.version`이 증가할 때마다 `OrderItem`, `OrderShipping`, `OrderSummary`, `OrderTransaction`, `OrderCreditLine` 모두 동기화.

**합계 계산**: 어떤 모델에도 `total`, `subtotal` 등이 컬럼으로 없음. `decorateCartTotals()`가 런타임 계산 후 `OrderSummary.totals` JSON에 저장.

---

## 엔티티 관계도

```
Order (version)
 ├── OrderAddress (shipping/billing)
 ├── OrderSummary (version별, totals JSON)
 ├── OrderItem[] (version별)
 │    └── → OrderLineItem (불변 스냅샷)
 │              ├── OrderLineItemAdjustment[] (할인 내역)
 │              └── OrderLineItemTaxLine[]
 ├── OrderShipping[] (version별)
 │    └── → OrderShippingMethod (배송비)
 │              ├── OrderShippingMethodAdjustment[]
 │              └── OrderShippingMethodTaxLine[]
 ├── OrderTransaction[] (결제/환불 내역)
 ├── OrderCreditLine[] (크레딧)
 ├── Return[]
 ├── OrderClaim[]
 └── OrderExchange[]
```

|------|------|------|

`totals` JSON 키:

```
# 현재 주문 상태
pending_difference        현재 주문 합계 - 결제 합계 (미결제 차액)
current_order_total       현재 주문 합계
original_order_total      최초 주문 합계
transaction_total         결제 거래 합계
paid_total                실 결제 금액
refunded_total            환불 금액
credit_line_total         크레딧 라인 합계
accounting_total          current_order_total - credit_line_total (정산 대상 금액)

# 아이템 합계
item_total / item_subtotal / item_tax_total
item_discount_total
original_item_total / original_item_subtotal / original_item_tax_total

# 배송 합계
shipping_total / shipping_subtotal / shipping_tax_total
shipping_discount_total
original_shipping_total / original_shipping_subtotal / original_shipping_tax_total

# 수량 기반 파생 합계
fulfilled_total / shipped_total
return_requested_total / return_received_total / return_dismissed_total
write_off_total
```

## 정산/과세 관련

`accounting_total = current_order_total - credit_line_total`

- `credit_line_total`: 포인트 등 크레딧으로 결제된 금액 (정산/과세 제외 대상)
- `accounting_total`: 실제 정산/과세 대상 금액

`OrderTransaction` ([`packages/modules/order/src/models/transaction.ts`](../../packages/modules/order/src/models/transaction.ts)):
- `amount > 0`: 결제
- `amount < 0`: 환불
- `reference` / `reference_id`: 어떤 Return/Exchange/Claim과 연관된 거래인지 추적

`OrderCreditLine` ([`packages/modules/order/src/models/credit-line.ts`](../../packages/modules/order/src/models/credit-line.ts)):
- 포인트 등 크레딧 사용 내역
- `reference` / `reference_id`로 크레딧 출처 추적
