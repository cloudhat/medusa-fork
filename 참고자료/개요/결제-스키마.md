# 결제 및 장바구니 모듈 스키마

Payment 모듈과 Cart 모듈의 DB 엔티티 구조. 포인트(크레딧), 부분 환불, 장바구니 금액 계산 구조 중심으로 정리.

상위: [README.md](README.md)

---

## Payment 모듈

### 엔티티 관계도

```
PaymentProvider ←M:M→ PaymentCollection
                              │
                    ┌─────────┼─────────┐
                    │                   │
             PaymentSession         Payment
                                       │
                               ┌───────┴───────┐
                             Refund          Capture
                               │
                           RefundReason
```

### PaymentCollection
[`packages/modules/payment/src/models/payment-collection.ts`](../../packages/modules/payment/src/models/payment-collection.ts)

| 필드                  | 타입                           | 비고                  |
| ------------------- | ---------------------------- | ------------------- |
| `amount`            | bigNumber                    | 전체 결제 금액            |
| `authorized_amount` | bigNumber, nullable          | 승인된 금액              |
| `captured_amount`   | bigNumber, nullable          | 실 수집 금액             |
| `refunded_amount`   | bigNumber, nullable          | 환불 합계 (부분 환불 누적 추적) |
| `status`            | enum PaymentCollectionStatus |                     |
| `currency_code`     | text                         |                     |

`status` 가능 값: `not_paid` / `awaiting` / `authorized` / `partially_authorized` / `canceled` / `failed` / `partially_captured` / `completed`

### Refund (부분 환불 지원)
[`packages/modules/payment/src/models/refund.ts`](../../packages/modules/payment/src/models/refund.ts)

| 필드 | 타입 | 비고 |
|------|------|------|
| `amount` | bigNumber | 환불 금액 (건당) |
| `note` | text, nullable | |
| `created_by` | text, nullable | |

한 `Payment`에 여러 `Refund` 레코드가 연결(1:N). 각 Refund가 독립 amount를 가지므로 부분 환불을 여러 번 INSERT하는 방식으로 지원.

`PaymentCollection.refunded_amount`가 누적 환불액을 집계.

## Cart 모듈

### 엔티티 관계도

```
Cart
 ├── Address (shipping/billing)
 ├── CreditLine[] (포인트 등 크레딧)
 ├── LineItem[]
 │    ├── LineItemAdjustment[] (할인)
 │    └── LineItemTaxLine[]
 └── ShippingMethod[]
      ├── ShippingMethodAdjustment[]
      └── ShippingMethodTaxLine[]
```

### Cart
[`packages/modules/cart/src/models/cart.ts`](../../packages/modules/cart/src/models/cart.ts)

DB 저장 필드 (금액 컬럼 없음):

| 필드 | 타입 |
|------|------|
| `currency_code` | text |
| `region_id` | text, nullable |
| `customer_id` | text, nullable |
| `email` | text, nullable |
| `completed_at` | dateTime, nullable |

computed 필드 (DB 미저장, 런타임 계산): `total`, `subtotal`, `tax_total`, `discount_total`, `shipping_total`, `item_total` 등 18개 이상.

### CreditLine (포인트/크레딧)
[`packages/modules/cart/src/models/credit-line.ts`](../../packages/modules/cart/src/models/credit-line.ts)

| 필드 | 타입 | 비고 |
|------|------|------|
| `amount` | bigNumber | 크레딧 사용액 |
| `reference` | text, nullable | 크레딧 출처 유형 (예: `"points"`) |
| `reference_id` | text, nullable | 크레딧 출처 ID |

Order 모듈의 `OrderCreditLine`([`packages/modules/order/src/models/credit-line.ts`](../../packages/modules/order/src/models/credit-line.ts))과 동일 구조. Cart → Order 전환 시 이관됨.

포인트 사용이 정산/과세에서 제외되는 근거: `accounting_total = current_order_total - credit_line_total`
